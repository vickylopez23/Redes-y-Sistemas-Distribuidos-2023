# Redes y Sistemas Distribuidos — FaMAF (UNC) 2023

Laboratorios de la materia **Redes y Sistemas Distribuidos** de la Licenciatura en Ciencias de la Computación (FaMAF, UNC), 2023. Recorren las capas de la red de arriba hacia abajo: aplicación, transporte y red.

**Grupo 16:** 

| Lab | Capa | Qué hicimos | Tecnología |
|-----|------|-------------|------------|
| [Lab 1](lab1) | Aplicación (cliente) | `hget`, un cliente HTTP con sockets | Python |
| [Lab 2](lab2) | Aplicación (servidor) | Servidor de archivos para el protocolo HFTP, con varios clientes a la vez | Python |
| [Lab 3](lab3) | Transporte | Análisis de congestión y control de flujo, y diseño de un algoritmo de control con feedback | Omnet++ (C++) |
| [Lab 4](lab4) | Red | Enrutamiento en una red en anillo: análisis del algoritmo base y diseño de uno que elige el camino más corto | Omnet++ (C++) |

Cada carpeta tiene su README con cómo correrlo y un `INFORME.md` con el informe que entregamos.

Los repositorios originales estaban en el Bitbucket de la cátedra (`redes23labXg16`).
